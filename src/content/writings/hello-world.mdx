## Starting a new post

1. Copy this file and rename it. The filename becomes the URL, so `my-post.mdx` lives at `/writings/my-post`.
2. Edit the front matter at the top (title, date, summary, kind).
3. Write below it in Markdown, then `git push`.

## What you can use

Regular paragraphs, *italics*, **bold**, `inline code`, and [links](https://nextjs.org/docs).
